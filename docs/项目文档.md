# 边境公司剧情视频生成器项目文档

## 项目概述

边境公司剧情视频生成器(LimbusCompanyPlotVideoGenerator)是一个用于自动生成《边狱公司》(Limbus Company)剧情视频的工具。该项目支持将剧情脚本转换为包含人物立绘、背景、音效和配音的完整视频。

## 技术架构

### 后端技术栈
- Java 21: 核心开发语言
- Spring Boot 3.2.0: 应用框架
- JavaCV: 视频处理和合成
- SQLite + JDBI: 数据持久化
- Jackson: JSON数据处理
- SLF4J + Logback: 日志管理

### 前端技术栈
- React 18: 用户界面框架
- Electron: 桌面应用封装
- Material-UI: UI组件库
- Axios: HTTP客户端
- react-beautiful-dnd: 拖拽功能

### 模块职责详细说明

#### 剧情处理模块 (plot)

**职责**：负责剧情的创建、编辑、解析和管理。

**核心类**：
- `RecordController`：处理剧情记录的HTTP请求（GET/POST/PUT/DELETE /api/records）
- `PlainTextRecordsParser`：将纯文本解析为剧情记录
- `Record`：剧情记录数据模型
- `Dialogue`：对白数据模型

**API端点**：
- `GET /api/records`：获取所有记录
- `POST /api/records`：创建新记录
- `PUT /api/records/{id}`：更新记录
- `DELETE /api/records/{id}`：删除记录
- `POST /api/text-to-records`：将纯文本解析为记录
- `POST /api/records/import`：导入记录文件
- `POST /api/records/export`：导出记录文件
- `POST /api/generate-video`：生成视频

#### 资源管理模块 (resource)

**职责**：管理角色、背景、音频等资源。

**核心类**：
- `CharacterController`：角色资源控制器
- `BackgroundController`：背景资源控制器
- `AudioController`：音频资源控制器
- `PortraitController`：立绘资源控制器
- `CharacterCardController`：角色名片图片控制器
- `CharacterService` / `BackgroundService`：服务接口
- `StorageService`：统一存储服务
- `MyCharacter`：角色数据模型
- `Background`：背景数据模型
- `Audio`：音频数据模型
- `Portrait`：立绘数据模型

**API端点**：
- `GET /api/characters`：获取角色列表
- `POST /api/characters`：创建新角色
- `PUT /api/characters/{id}`：更新角色
- `DELETE /api/characters/{id}`：删除角色
- `GET /api/backgrounds`：获取背景列表
- `POST /api/backgrounds/upload`：上传背景文件
- `POST /api/backgrounds`：添加背景
- `PUT /api/backgrounds/{id}`：更新背景
- `DELETE /api/backgrounds/{id}`：删除背景
- `GET /api/audios`：获取音频列表
- `POST /api/audios`：添加音频
- `PUT /api/audios/{id}`：更新音频
- `DELETE /api/audios/{id}`：删除音频
- `POST /api/characters/{characterId}/portraits`：添加立绘
- `PUT /api/characters/{characterId}/portraits/{portraitId}`：更新立绘
- `DELETE /api/characters/{characterId}/portraits/{portraitId}`：删除立绘
- `GET /api/character-card/{characterId}`：获取角色名片图片

#### 视频渲染模块 (render)

**职责**：将剧情记录渲染为视频。

**核心类**：
- `FrameComposerService`：帧合成服务
- `BatchVideoProcessor`：批量视频处理器
- `VideoExporter`：视频导出器
- `AudioTimelineBuilder`：音频时间线构建器
- `FFmpegAudioProcessor`：FFmpeg音频处理器

**API端点**：
- `GET /api/plot-video/health`：健康检查
- `GET /api/plot-video/init-audio`：初始化音频系统
- `GET /admin/async-jobs/status`：获取异步任务状态
- `GET /admin/async-jobs/task/{id}`：获取任务详情
- `GET /admin/async-jobs/failed`：获取失败任务列表

#### 配置模块 (config)

**职责**：管理应用配置。

**核心类**：
- `ProjectConfig`：项目配置类（包含资产路径等静态常量）
- `StorageConfig`：存储配置类
- `WebMvcConfig`：Web配置类
- `AsyncQueueProperties`：异步队列配置
- `DatabaseConfig` / `DatabaseInitializer`：数据库配置与初始化
- `AppConfig` / `AppProperties`：应用配置与属性

#### 公共模块 (common)

**职责**：提供通用功能和工具。

**核心类**：
- `RecordsIO`：Record对象的JSON读写
- `ImageReader` / `ImageExporter`：图像读取与导出
- `ColorUtils` / `ColorSpaceConverter`：颜色处理
- `SQLiteDatabaseManager`：SQLite数据库管理
- `VideoAudioMerger`：音视频合并

## 核心功能模块

### 1. 剧情编辑模块
- 功能：提供剧情记录编辑界面，支持对白、角色、背景、特效和音频的全面编辑
- 实现：RecordEditor组件、RecordController、Record模型
- 主要API：`/api/records/*`

### 2. 资源管理模块
- 功能：集中管理角色立绘、背景图片和音频资源
- 实现：ResourceManager组件、CharacterController、BackgroundController、AudioController
- 主要API：`/api/characters/*`, `/api/backgrounds/*`, `/api/audios/*`

### 3. 文本转剧情模块
- 功能：支持将纯文本脚本自动转换为剧情记录
- 实现：TextToRecords组件、PlainTextRecordsParser
- 主要API：`POST /api/text-to-records`

### 4. 视频渲染模块
- 功能：将剧情记录渲染为视频帧并合成最终视频
- 实现：FrameComposerService、BatchVideoProcessor、VideoExporter
- 主要API：`POST /api/generate-video`

## 数据模型

### 核心数据模型
1. **Record**: 剧情记录，包含对白、摄像机、背景、角色、特效与音频等
2. **Dialogue**: 对白文本，包含说话人、位置、对齐、速度、情绪等
3. **CharacterVisual**: 角色立绘的可视化表示
4. **BackgroundVisual**: 背景资源与显示属性
5. **AudioCommand**: 音频命令/片段

### 资源模型
1. **MyCharacter**: 完整的角色实体
2. **Portrait**: 立绘数据
3. **Background**: 背景资源

## 资产路径配置化重构说明

### 背景
为减少硬编码路径带来的维护成本，并支持在不同部署环境中使用自定义资源目录，已将代码库中对 `assets/*` 的直接字符串引用逐步迁移为可配置项或常量。

### 变更要点
- 使用后端配置 `project` / `app.assets`（由 `ProjectConfig` 与 `AppConfig` 提供）替代硬编码路径。
- 增强 `ImageReader`：在类路径与文件系统中基于配置查找资源，支持按配置回退查找。
- 前端：将常用静态资源相对路径抽成常量（Electron 主进程示例），并采用集中配置以生成资源 URL。

### 可配置项位置
- 应用配置（优先）: `demo/src/main/resources/application.yml` 或 `application-dev.yml` / `application-prod.yml`
- 备用配置: `demo/src/main/resources/storage.properties`

### 可覆盖的配置键
- `app.assets.path`：资产根目录
- `app.assets.backgrounds`：背景目录
- `app.assets.characters`：人物目录
- `app.assets.thumbnails`：缩略图目录
- `app.assets.audios`：音频目录
