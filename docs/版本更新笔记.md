
## 未发布

- "剧情编辑"页"剧情列表"新增**分组**（类似 Photoshop 的图层文件夹）：
  - 标题旁新增「📁+ 新建分组」按钮，紧挨"添加记录"的「+」
  - 把记录拖到分组表头即可加入分组；按住 Ctrl / Shift 可多选，多选后能一次性拖入
  - 记录行首新增拖拽手柄（⠿）：拖动即可调整记录顺序，或拖进/拖出分组
  - 拖到组内某条记录的上/下半区可指定插入位置
  - 拖动时列表上/下沿各浮出一条放置区（"拖到这里：放到列表最前面 / 移到末尾"），拖上去即可把内容移到最前/最后并移出分组；
    放置区贴在列表可视区边缘、不随表格滚动，剧情很长、列表滚到中间时也始终看得见、放得下
  - 拖动分组时同样可以用这两条放置区把整组放到最前/最后
  - **分组表头也可以拖动排序**：整组（连同组内记录）一起移动，可以放到任意两条内容之间；空分组同样能拖到内容中间
  - 双击分组名称或点 ✏️ 重命名；点箭头折叠/展开（折叠后表头仍显示记录条数）；点 ✕ 解散分组（组内记录保留，变为未分组）
  - 当前记录选中态更明显：高亮底色 + 深色描边 + 序号旁实心圆点（不做闪动动画）
  - 多选但非当前记录的行也有独立标记：更明显的浅蓝底色 + 空心蓝圈
  - 有记录的分组随工程保存 / 导入（名称、折叠状态、位置都保留）；空分组只在当前会话中保留，拖入记录后即可随工程保存
- 在分组内按「+」新增记录时，新记录留在当前分组（插到组内末尾），不会跑到列表最下面；分组被折叠时会自动展开
- 删除记录或拖动重排后，预览图与属性面板跟随的记录不再错位（选中项按 uuid 追踪）
