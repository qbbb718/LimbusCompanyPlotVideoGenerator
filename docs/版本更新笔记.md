## 0.6.0（未发布）
- **情绪动画（序列帧）**：给一个立绘挂一段"贴脸的帧序列动画"
  - 导入若干张 PNG/JPG 序列帧（多选 / 文件夹里全选），自动按**文件名自然排序**
    （`frame_9` 在 `frame_10` 前面），各帧尺寸不一致时自动居中贴到公共画布并提示
  - 每张图可单独设定**持续帧数**，另有"全部设为 N 帧"批量操作
  - 序列级**透明度补间**：淡入帧数 / 淡出帧数 / 整体不透明度（循环模式下淡出强制为 0）
  - 播放模式：播一次 / 播完停住 / 循环 / 往返，可设循环次数与延迟帧
  - 位置跟随立绘：以**脸框中心**为锚点、跟着用户缩放一起变大变小，并跟着立绘的移动动画一起动
  - 静止预览显示**代表帧**（可在面板上从序列里挑一张），避免淡入起点全透明看起来像"素材没导入"
  - 素材存在 `assets/animation-clips/<id>/`，**可跨记录复用**；面板里可直接从素材库挑一套
  - **动画文件导入导出**：`.lcaf`（本质是 zip：`clip.json` + `frames/*.png`），
    导出再导入会原样保留每帧时长
  - 素材被删除/拷漏时只是"那一帧不画"，不会让工程打不开、也不会让导出失败
  - **不参与记录时长**：素材再长也只会播到记录结束为止（避免一个循环特效把整条视频拉长几十秒）
  - 没挂情绪动画的记录渲染路径**逐像素不变**（渲染基线测试照旧通过）
- **【重构】序列帧动画的制作入口搬到「资源管理」**
  - 资源管理新增子页面「序列帧动画」：建（选图片 / 从文件夹 / 导入 .lcaf）、列表、改名、
    每帧持续时间、播放参数、删除、导出 `.lcaf`
  - 该子页面自带**合成预览**：背景 + 立绘 + UI 三层由后端按成片同一套管线渲出来，
    代表帧以可拖拽、可滚轮缩放的叠加层盖在最上面，所见即所得
  - 代表帧的摆放存成**相对头部区域**的偏移（单位 = 头宽）与缩放倍率，所以**换角色也能复用**：
    切角色后代表帧仍然落在同一个相对位置（头部方框跨角色恒为 183 场景像素）
  - 剧情编辑页的立绘 tab **不再包含任何制作 UI**：只剩「选用动画」下拉 +
    「前往资源管理编辑动画 →」跳转（跳到资源管理并自动停在「序列帧动画」子页面）
  - 播放参数（循环/淡入淡出/不透明度/开始帧）与代表帧一并收口到素材上；
    记录里仍保留一份内联快照（渲染不读盘、老工程画面不因改素材而变），
    需要同步时由用户点「从素材同步」
  - 修：`.lcaf` 导出再导入会丢掉播放参数与代表帧摆放（现在完整还原）
- **【续】序列帧动画：播放预览、淡入淡出分离、背景修复、剧情预览跟随**
  - 资源管理 → 序列帧动画的预览区新增**播放 / 暂停 / 停止 + 循环播放**：
    按每帧持续帧数与淡入淡出真实播放；**播放中锁定代表帧的拖拽/缩放**，暂停或停止后恢复可编辑
  - **淡入、淡出拆成两个独立参数**（各自滑杆 + 数字框），改完立刻在播放预览里生效；
    循环/往返模式下淡出仍强制为 0（否则每轮接缝一淡一显）
  - **修复背景图片加载失败**（按运行日志定位）：资源管理把背景路径补成了
    `http://localhost:8081/assets/...` 用于 `<img>`，又被当成"记录里的素材路径"发给后端，
    后端把它当文件名拼成 `.../backgrounds/http://localhost:8081/assets/...`，背景**静默变黑**。
    修法两层：① 合成预览改用**原始路径**；② 后端解析素材路径时先剥掉 URL 外壳（老数据自愈），
    并在日志里明确告警；③ 预览区对背景可达性做探测，加载失败直接显示红条，不再静默
  - **剧情编辑的预览图也会画代表帧**：静止时画「代表帧」（与后端栅格图同一口径），
    播放时画真实序列帧；拖动/缩放/切换立绘时代表帧按"相对头部区域"的变换实时跟随
- **【续】导入时按文件名编号自动推算每帧时长**
  - 导入的图片文件名带规律编号时，自动按"相邻编号差值"设每张图的持续帧数：
    `xxx_1/2/3/7/9.png` → **1 / 1 / 4 / 2 / 最后一张默认 1 帧**（需求里的例子）
  - 识别规则：同一批共享相同前后缀模板（只编号不同）、编号可解析为整数且**严格递增**
  - **不推算也不报错**的情况：没有编号、单张图、命名混乱 —— 导入照常完成，保持每张 1 帧
  - **会给提示**的情况：重复编号、前缀不一致（不属于同一序列）、编号逆序、
    相邻差值超过上限（默认 60 帧，超出截断）、推算总时长超过 900 帧上限（整体回落每张 1 帧）
  - 资源管理 → 序列帧动画左侧新增「按文件名编号推算时长」开关（默认开启，记住选择）
  - 推算结果直接显示在每张图的时长输入框里，**可以逐张手改**；手改的值立即落库，不会被后来的导入覆盖
- **【续】序列帧动画子页面的 UI 重构（响应式 / 缩略图 / 单键播放）**
  - **术语统一**：界面上的「代表帧」全部改叫**「缩略图」**（含按钮、提示、字段标签、无障碍名称）；
    数据字段仍是 `poster` / `posterFrame`，语义（静止预览显示的那一张 + 跨角色复用）不变
  - **窗口自适应**：改为 grid/flex + 容器查询——宽窗口三栏并排；≤1180px 收窄两侧；
    ≤900px 预览与设置**上下堆叠**；≤720px 素材列表也叠到最上方并变成横向卡片行。
    行内控件按"标签 + 输入框"**成组换行**，窗口再窄也不会把标签和输入框拆到两行；
    各区块都有 min-width/min-height，挤不下就滚动，长文本单行省略 + 悬浮看全文
  - **缩略图选择交互**：帧序列区块新增「选择缩略图」按钮，按下后帧列表进入待选态
    （按钮高亮 + 虚线框 + "请点击某一帧设为缩略图"），点某帧即设为缩略图并退出；
    再点按钮或按 `Esc` 取消（不改变当前缩略图）；当前缩略图用**角标 + 金边框**标出；
    进待选态会先停止播放，选定只换"哪一张"，相对头部区域的偏移/缩放原样保留
  - **预览图固定 16:9**：实测视口像素算最大等比矩形，居中留白、只等比缩放不变形
    （不依赖 `aspect-ratio + max-height`，那套在两个方向同时受限时会破比例）；舞台尺寸是纯函数 `fitStage`
  - **播放/停止合并成单键双态**：未播放显示「▶ 播放」，播放中显示「⏹ 停止」，
    状态直接由播放相位推导；点停止**回到初始状态**（显示缩略图、解锁拖拽）。暂停仍是独立键。
    播到末尾：勾选「循环播放」从头再播，不勾则自动停止并回到缩略图（有限循环次数按"总帧数 × 次数"算末尾）
  - **页面收敛成两个区块**：「播放参数」+「帧序列」。原来的「缩略图」区块删掉——
    挑哪一张、当前是哪一张、以及相对头部的摆放（偏移/缩放）全部并进「帧序列」，不再重复两套入口
  - **修：不同动画的参数互相串**。换素材时没有重建草稿，上一套的淡入淡出/播放参数/每帧时长/缩略图
    会被带进新选中的那套，保存时还会把这些值写到错误的素材上。现在草稿跟着素材 id 走：
    切过去就是它自己的值；切走前防抖窗口里没落库的改动会先**补存回原来那套**，不会丢也不会串
  - 顺带两处一致性：改每帧时长后**立刻**按新节奏试播（原来要等保存回包）；
    保存触发的列表刷新不再让编辑区闪回空白（用记住的素材 + 当前草稿续渲，预览不会被卸载）

  - 剧情编辑的属性栏新增 **「🎥 摄像机」页签**，与「立绘」「背景」同级（排在「背景」后面）：

    取消勾选仍按老语义直接删掉这一条

    **渐出**（满幅度 → 0 用多少帧，对齐抖动结束；持续为 0 时对齐记录结尾）。
    三个参数缺省都是 0，所以**老工程与老预设的行为一个字都没变**
  - 时间包络 `env = min(渐入, 渐出)` 与位移公式前后端**逐字一致**

  - 顺带修一个导出侧的老问题：`RenderOfVideo` 的逐帧渲染条件原来只看"镜头会动 / 立绘动画"，

    现在摇动也会触发逐帧重渲，并把记录总帧数传给摇动求值（渐出要用）
  - 「摄像机」页签的世界视图顶部**也有「▶ 播放」**了：点一下临时切成**成片预览**
    （同一个播放头播运镜 + 摇动 + 立绘动画），播完或停止后自动回到世界视图
  - 面板里的「▶ 播放」按钮改名为「▶ 播放运镜」，与预览顶部的成片预览区分
  - **页面提示文字整体精简**：属性面板里的长说明都压成一行，细节挪进按钮 / 参数的悬浮提示——
    覆盖摄像机页签、预设区块、特效页签、背景、文本（自由文字）、全局设置（文字速度 / 结尾停留）、
    立绘动画面板、情绪动画选择器、关键帧时间轴与预览播放提示
