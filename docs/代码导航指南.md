## 代码导航策略

### 1. 功能导向导航

当需要实现某个功能时，按照以下步骤导航：

1. **关键词搜索**：使用功能相关的关键词进行搜索
   - 示例：搜索"文本转剧情"、"视频渲染"、"资源管理"等

2. **模块定位**：根据模块索引定位相关代码
   - 示例：文本转剧情功能在"plot"模块中

3. **API查找**：在API端点索引中查找相关API
   - 示例：文本转剧情对应API为 `POST /api/text-to-records`

4. **实现追踪**：从API端点追踪到具体实现代码
   - 示例：从 `RecordController.textToRecords()` 到 `PlainTextRecordsParser.parseText()`

### 2. 问题导向导航

当需要修复某个问题时，按照以下步骤导航：

1. **错误信息搜索**：使用错误信息中的关键词进行搜索
   - 示例：搜索"UnsatisfiedLinkError"、"NullPointerException"等

2. **日志关联**：查看日志文件，定位出错的代码位置
   - 开发模式：`demo/logs/`（前后端日志同目录，前端副本文件名带 `-2` 后缀）
   - 安装版：`%APPDATA%\limbus-company-plot-video-generator\logs\`
   - 用户不会自己找目录：设置页「获取日志」按钮会把最新 10 个日志打包成 zip 发给开发者

3. **版本对比**：如果是引入新问题，对比代码变更
   - 示例：使用Git对比最近的代码变更

### 3. 组件关联导航

当需要修改某个组件时，按照以下步骤导航：

1. **组件定位**：在组件索引中查找组件位置
   - 示例：ResourceManager组件在 `features/common/components/ResourceManager/ResourceManager.tsx`

2. **依赖分析**：分析组件的依赖关系
   - 示例：ResourceManager依赖 `ApiService`、各类资源类型

3. **影响评估**：评估修改可能影响的其他组件
   - 示例：修改ResourceManager可能影响RecordEditor中的资源选择

## 搜索技巧

### 1. 关键词组合

使用多个关键词组合进行精确搜索：

- **功能+类型**：如"剧情解析器"、"视频渲染器"
- **模块+功能**：如"音频模块处理"、"资源模块加载"
- **API+功能**：如"角色API"、"背景API"

### 2. 文件类型过滤

根据需要搜索特定类型的文件：

- **Java后端**：搜索 `.java` 文件
- **React组件**：搜索 `.tsx` 文件
- **样式文件**：搜索 `.css` 或 `.scss` 文件
- **配置文件**：搜索 `.xml`、`.json` 或 `.properties` 文件

### 3. 路径模式

使用路径模式缩小搜索范围：

- **后端代码**：搜索 `demo/src/main/java/` 路径
- **前端代码**：搜索 `demo/frontend/electron-react-app/src/` 路径
- **资源文件**：搜索 `demo/src/main/resources/` 路径

### 4. 注释标签

利用注释标签进行定向搜索：

- 搜索 `@module` 标签查找特定模块
- 搜索 `@function` 标签查找特定功能
- 搜索 `@api` 标签查找特定API
- 搜索 `@model` 标签查找特定数据模型

## 后端模块索引

### 核心模块

1. **剧情处理模块 (plot)**
   - 路径: `demo/src/main/java/com/lbc_plot/plot/`
   - 功能: 处理剧情数据、解析文本、生成Record对象
   - 主要类:
     - `RecordController`: Record API控制器
     - `PlainTextRecordsParser`: 纯文本解析器
     - `Record`: 剧情记录数据模型
     - `Dialogue`: 对白数据模型

2. **视频渲染模块 (render)**
   - 路径: `demo/src/main/java/com/lbc_plot/render/`
   - 功能: 将Record对象渲染为视频帧
   - 主要类:
     - `FrameComposerService`: 帧合成服务
     - `BatchVideoProcessor`: 批量视频处理器
     - `VideoExporter`: 视频导出器
     - `RenderOfImage` / `RenderOfVideo`: 渲染器
     - `AudioTimelineBuilder`: 音频时间线构建器
     - `FFmpegAudioProcessor`: FFmpeg音频处理器

3. **音频处理模块 (render/audio)**
   - 路径: `demo/src/main/java/com/lbc_plot/render/audio/`
   - 功能: 处理音频、生成时间线
   - 主要类:
     - `AudioTimelineBuilder`: 音频时间线构建
     - `FFmpegAudioProcessor`: FFmpeg音频处理
     - `AudioCommand` / `AudioTimeline` / `AudioSegment`: 音频模型

4. **资源管理模块 (resource)**
   - 路径: `demo/src/main/java/com/lbc_plot/resource/`
   - 功能: 管理角色、背景、音频等资源
   - 主要类:
     - `CharacterController`: 角色控制器
     - `BackgroundController`: 背景控制器
     - `AudioController`: 音频控制器
     - `PortraitController`: 立绘控制器
     - `CharacterService` / `BackgroundService`: 服务接口
     - `StorageService`: 统一存储服务
     - `MyCharacter` / `Portrait` / `Background` / `Audio`: 数据模型

5. **公共模块 (common)**
   - 路径: `demo/src/main/java/com/lbc_plot/common/`
   - 功能: 通用工具和功能
   - 主要类:
     - `RecordsIO`: Record JSON读写
     - `ImageReader` / `ImageExporter`: 图像读写
     - `ColorUtils`: 颜色工具
     - `VideoAudioMerger`: 音视频合并

6. **配置模块 (config)**
   - 路径: `demo/src/main/java/com/lbc_plot/config/`
   - 功能: 应用配置管理
   - 主要类:
     - `ProjectConfig`: 项目配置（含资产路径常量）
     - `StorageConfig`: 存储配置
     - `DatabaseConfig` / `DatabaseInitializer`: 数据库配置与初始化
     - `AppConfig` / `AppProperties`: 应用配置

## API端点索引

### 剧情记录API
- `GET /api/records` - 获取所有记录
- `POST /api/records` - 创建新记录
- `PUT /api/records/{id}` - 更新记录
- `DELETE /api/records/{id}` - 删除记录
- `POST /api/text-to-records` - 文本转记录
- `POST /api/records/import` - 导入记录
- `POST /api/records/export` - 导出记录
- `POST /api/generate-video` - 生成视频

### 角色API
- `GET /api/characters` - 获取角色列表
- `POST /api/characters` - 创建角色
- `PUT /api/characters/{id}` - 更新角色
- `DELETE /api/characters/{id}` - 删除角色

### 立绘API
- `POST /api/characters/{characterId}/portraits` - 添加立绘
- `PUT /api/characters/{characterId}/portraits/{portraitId}` - 更新立绘
- `DELETE /api/characters/{characterId}/portraits/{portraitId}` - 删除立绘
- `PUT /api/characters/{characterId}/portraits/{portraitId}/default` - 设置默认立绘

### 背景API
- `GET /api/backgrounds` - 获取背景列表
- `GET /api/backgrounds/{id}` - 获取单个背景
- `POST /api/backgrounds/upload` - 上传背景文件
- `POST /api/backgrounds` - 添加背景
- `PUT /api/backgrounds/{id}` - 更新背景
- `DELETE /api/backgrounds/{id}` - 删除背景
- `POST /api/backgrounds/{id}/thumbnail` - 上传缩略图

### 音频API
- `POST /api/audios/upload` - 上传音频文件（落到 `{dataRoot}/assets/audios`，返回 URL 形式的 `path`）
- `GET /api/audios` - 获取音频列表
- `POST /api/audios` - 添加音频（存元数据，需先调 upload 取得 path）
- `PUT /api/audios/{id}` - 更新音频
- `DELETE /api/audios/{id}` - 删除音频
- `GET /api/audios/{id}/file` - 获取音频文件（兼容库里存的 URL 形式路径）

### 角色名片API
- `GET /api/character-card/{characterId}` - 获取角色名片图片

### 系统API
- `GET /api/health` - 健康检查
- `GET /api/plot-video/health` - 视频服务健康检查
- `GET /api/plot-video/init-audio` - 初始化音频系统

### 异步任务管理API
- `GET /admin/async-jobs/status` - 任务队列状态
- `GET /admin/async-jobs/task/{id}` - 任务详情
- `GET /admin/async-jobs/failed` - 失败任务列表
