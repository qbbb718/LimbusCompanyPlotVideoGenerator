# 前端架构文档

本文档描述前端应用的架构设计、组件组织和数据流。

## 技术栈

- **React 18**: UI框架
- **TypeScript**: 类型安全
- **Electron**: 桌面应用封装
- **Material-UI (MUI)**: 组件库
- **Axios**: HTTP客户端
- **electron-log**: 日志记录

## 组件架构

### 1. 剧情编辑器 (RecordEditor)

**路径**: `features/common/components/RecordEditor/`

**职责**: 提供剧情记录的完整编辑功能，包括列表展示、预览和属性编辑。

**组件层级**:
```
RecordEditor
├── RecordList              # 记录列表（下方表格）
├── RecordPreview           # 记录预览（左上方）
├── ResizablePanel          # 可调整大小的面板
└── PropertyTabs            # 属性标签页（右上方）
    ├── TextProperties      # 文本属性
    ├── CharactersProperties# 角色/立绘属性
    ├── BackgroundProperties# 背景属性
    ├── AudioProperties     # 音频属性
    └── GlobalProperties    # 全局属性
```

**数据流**:
1. 从 `ApiService.getRecords()` 加载记录列表
2. 用户选择记录 -> `selectedRecord` 状态更新
3. 属性编辑 -> 修改 `selectedRecord` -> 调用 `ApiService.updateRecord()`
4. 列表操作（增删改）-> 更新记录列表 -> 同步到后端

### 2. 资源管理器 (ResourceManager)

**路径**: `features/common/components/ResourceManager/`

**职责**: 管理角色、背景、音频等资源，支持CRUD操作。

**组件层级**:
```
ResourceManager
├── ResourceTabs            # 资源标签页
│   ├── CharactersTab       # 角色标签
│   │   ├── CharacterDetailModal  # 角色详情弹窗
│   │   │   ├── CharacterInfoSection
│   │   │   ├── ColorPicker
│   │   │   ├── NamePreview
│   │   │   ├── PortraitsSection
│   │   │   └── TagsSection
│   │   └── PortraitModal   # 立绘编辑弹窗
│   │       ├── PortraitPreview
│   │       └── PortraitSettings
│   ├── BackgroundsTab      # 背景标签
│   │   ├── BackgroundCard
│   │   └── BackgroundModal
│   └── AudiosTab           # 音频标签
└── AdvancedImageCropper    # 高级图像裁剪器
```

**数据流**:
1. 从 `ApiService.getCharacters()` / `getBackgrounds()` / `getAudios()` 加载资源
2. 用户编辑资源 -> 调用对应 API 更新
3. 上传文件 -> `multipart/form-data` 提交到后端

```

**文本格式**:
```
[BGM名称]
{背景图片名称}
说话人: 对话内容(情绪)
旁白: 对话内容
[-STOP]
```

**数据流**:
1. 用户输入文本
2. 点击转换 -> `ApiService.textToRecords(text)`
3. 后端解析返回 `Record[]`
4. 结果可导入到 RecordEditor

### 核心类型定义

**路径**: `features/common/types/index.ts`

## 状态管理

当前前端使用 **React 内置状态管理**（useState/useReducer），未引入 Redux/MobX 等外部状态库。

### 状态分布

- **RecordEditor**: 管理 `records` 列表和 `selectedRecord`
- **ResourceManager**: 管理 `characters`、`backgrounds`、`audios` 列表
- **TextToRecords**: 管理输入文本和解析结果
- **Settings**: 管理设置项

### 数据持久化

- 业务数据（记录、角色等）持久化到后端数据库
- 应用设置可保存到本地存储（localStorage）

## API 通信

**服务层**: `features/common/ApiService.ts`

使用 Axios 封装所有后端 API 调用，提供统一的错误处理和日志记录。

> **完整的 REST API 端点列表（URL、请求体、响应格式）** 请参考 `API文档.md`。

```typescript
class ApiService {
  // 记录操作
  async getRecords(): Promise<Record[]>
  async createRecord(recordData: any): Promise<Record>
  async updateRecord(id: string, recordData: any): Promise<Record>
  async deleteRecord(id: string): Promise<void>

  // 角色操作
  async getCharacters(): Promise<MyCharacter[]>
  async addCharacter(characterData: any): Promise<MyCharacter>
  async updateCharacter(id: string, characterData: any): Promise<MyCharacter>
  async deleteCharacter(id: string, deleteFiles?: boolean): Promise<void>

  // 立绘操作
  async addPortrait(characterId: string, portraitData: any): Promise<Portrait>
  async updatePortrait(characterId: string, portraitId: string, portraitData: any): Promise<Portrait>
  async deletePortrait(characterId: string, portraitId: string, deleteFiles?: boolean): Promise<void>

  // 背景操作
  async getBackgrounds(): Promise<Background[]>
  async getBackground(id: string): Promise<Background>

  // 音频操作
  async getAudios(): Promise<Audio[]>

  // 文本转换
  async textToRecords(text: string): Promise<Record[]>

  // 视频生成
  async generateVideo(records: any[]): Promise<string>
}
```

## 样式组织

- 每个主要组件拥有独立的 `.css` 文件

## 日志系统

使用 `electron-log` 记录前端日志：
- 主进程日志: `[main:level]`
- 渲染进程日志: `[renderer:level]`
- 日志文件: `demo/frontend/electron-react-app/logs/frontend-{timestamp}.log`

```

## 注意事项

1. **路径问题**: Electron 中需要区分开发环境和生产环境的资源路径
2. **CORS**: 开发时前端端口为3000，后端为8080，已配置跨域
3. **大文件**: 上传大图片/音频时显示加载状态，避免界面卡死
4. **内存管理**: 大量图片预览时注意释放 Blob URL
