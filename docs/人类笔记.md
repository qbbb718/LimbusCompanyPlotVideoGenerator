
## 打包分发

### Github Action打包

git push origin :refs/tags/v0.1.3
git tag -d v0.1.3

# 查看当前版本、以及各处版本号是否一致
node scripts\version.mjs
# 改成 0.2.4（加 --write 才真正落盘）
node scripts\version.mjs 0.2.4 --write
# 只校验不改（CI 用）：--check 比对各处是否一致，--check-tag 额外要求 git 里已有该 tag
node scripts\version.mjs --check
node scripts\version.mjs --check-tag v0.2.4
# 版本工具自测（改过 scripts\version.mjs 后跑一次）
node scripts\version.test.mjs

git tag v0.3.1
git push origin main v0.3.1


### 本地打包
```
E:\LimbusCompanyPlotVideoGenerator\demo\build-package.bat
```
安装包默认落在仓库根的 [release](E:\LimbusCompanyPlotVideoGenerator\release\)，
构建日志在 `demo\logs\build-<时间戳>.txt`，注意事项（管理员权限、目录被占用、
安装路径不能带空格）见 [本地打包说明](本地打包说明.md)。

> 旧脚本 `build-package.ps1` 已删除：它把 `npm run build` 放在 electron-builder **之后**，
> 打出来的安装包缺前端 `build/`，安装后界面打不开。只用上面的 `.bat`。

[用户使用日志](C:\Users\user\AppData\Roaming\limbus-company-plot-video-generator\logs)

（用户报错时不用让他们自己找这个目录：设置页有「获取日志」按钮，会把最新 10 个日志打包并弹保存窗口。）
